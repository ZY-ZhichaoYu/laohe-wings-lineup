# 2026-11-05 发布版浏览器验收

本记录检查本机构建的 `dist/`，不代替 CloudBase 真实环境验收。使用独立 Chromium 浏览器会话，网址为 `http://127.0.0.1:8765/dist/index.html`。

## 已验证

- 两队在 320、390、768、1440 像素宽度下均无页面横向溢出，报名与 MVP 表单没有超出卡片边界。之翼 15 人、只因 18 人，均为 8 名首发。
- 两队主客场共四种海报实际点击导出成功。检查首发、替补和领队照片：没有跨用另一套球衣的文件；只因客场的李炳灿、沈熙洲、徐文浩均为蓝衣卡。
- 放大查看张子冲、新 9 号和原有球员卡的号码、边框、球衣及照片。张子冲使用主场 v4 和客场 v4，三位新增球员使用 v2；完整来源及提示词见前一轮制作记录。
- 图片导出前主动加载视口外的替补和领队照片；导出后恢复原加载方式。四张 PNG 均保留照片，没有把毕业档案混入比赛海报。
- 390 像素宽度实际打开手机导出预览，生成 1520×3294 PNG，显示“手机端请长按图片保存”。这是桌面 Chromium 的窄屏验证，不能代替真实 iOS / 微信浏览器测试。
- 旧 11 人制仍显示 11 名首发。球队记忆的三张旧照可正常加载，独立于比赛海报。
- 已确认本机域名不启用 CloudBase 同步，并在浏览器会话阻断所有外部写请求，再试填报名和 MVP：页面分别反馈“已本地报名”和“已本地投 MVP”。未向共享数据库提交测试记录。
- 检查过程中没有前端脚本异常，也没有本机资源 404。
