# 第三轮实际交互调试

日期：2026-10-29。开发目录 `laohe-wings-lineup-upgrade`。此前的检查覆盖不足，用户指出张子冲蓝色卡仍是旧照；本轮补齐蓝卡，并从实际操作重新核查。

## 已复现并修复的问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 替补改号码，再改同一行姓名会串改另一人 | 海报渲染原地排序替补数组，管理输入仍保存旧索引 | 排序显示副本并保留原索引，管理输入保持焦点 |
| 替补伤停修改后海报与名单不更新 | 状态事件只刷新首发 | 同时刷新替补与完整名单 |
| 清照后仍显示内置照片，刷新又恢复 | 默认照片回退无法区分缺照与主动删除 | 保存明确的禁用默认照片标记，兼容旧缺照记录，并应用到预设、球员、教练、领队、传奇卡 |
| 解锁编辑后不能直接鼠标拖拽 | 卡片保留只读时的 draggable=false | 编辑状态切换同步卡片可拖动属性 |
| 手机首发拖动被取消 | 浏览器默认滚动手势触发 pointercancel | 编辑模式下对可拖卡片设置 touch-action:none，只读替补恢复正常滚动 |

张子冲红、蓝新版均以用户指定的新原照编辑。蓝色路径为 `assets/players/20-张子冲-away-v2.png`。默认数据修订号升为 4：仅替换精确旧内置路径，保留自上传照片、康复状态、首发及互动数据。
